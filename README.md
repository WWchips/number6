# Практическое занятие 6

Этот репозиторий содержит материалы по учебному проекту по управлению продуктом и Agile-практикам.

## Содержимое

- `Практическое занятие 6/` — основная папка с заданиями и исходниками
- `shop.py` — реализация функций каталога и заказов
- `docs/` — backlog, Kanban, заметки стендапа и ретроспектива

## Как открыть проект

1. Откройте папку `Практическое занятие 6/`.
2. Изучите файлы `README.md`, `shop.py` и папку `docs/`.
3. Используйте материалы как основу для работы по Scrum/Kanban и анализу проекта.

## Git

Чтобы зафиксировать изменения и отправить репозиторий на GitHub:

```bash
git add .
git commit -m "Добавлены материалы практического занятия 6"
git push origin main
```

Если репозиторий только что создан и ещё не привязан к GitHub:

```bash
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```
